Logo File Formats Explained: PNG, JPG, SVG, PDF and When to Use Each

Confused by all the logo file types? Here is a plain-English guide to PNG, JPG, SVG, PDF, AI and EPS, and which one to use for the web and for print.

CategoryBranding
Published23 Oct 2026
Reading time3 min

You have just received your new logo, and the folder is full of files with strange extensions. Which one goes on your website? Which one do you send to the printer? This guide explains each format in plain language, so you always pick the right one.

First: vector or raster?

Almost every file type falls into one of two groups.

  • Raster images (JPG, PNG, GIF, WebP) are made of a fixed grid of tiny coloured squares called pixels. Make them bigger and they go blurry, because there is no extra detail to show.
  • Vector images (SVG, AI, EPS) are made of mathematical shapes and lines. You can scale them to any size, from a favicon to a billboard, without losing sharpness.

This is why logos should always be created as vectors. A raster copy can be made from a vector at any time, but it is hard to go the other way.

The formats you will see

Format Type Best for Background
SVG Vector Logos and icons on websites Can be transparent
PNG Raster Websites, email, anywhere you need a transparent background Can be transparent
JPG Raster Photographs and images with lots of colour Solid only
PDF Vector and raster Print, and sharing documents Depends on how it was made
AI Vector Editing in Adobe Illustrator, print Artwork only, no background
EPS Vector Editing across different programs, print Artwork only, no background

SVG

The best choice for a logo on a website. It stays sharp on every screen, including very high-resolution ones, and the file is often very small, so it loads fast.

PNG

A reliable, widely supported image format that keeps a transparent background, so your logo can sit on top of a coloured section or photo without a white box around it. Use it where SVG is not accepted, such as some social media profiles and email signatures. Because it is raster, make sure you use a size big enough for where it will appear.

JPG

Great for photos, but a poor choice for logos. JPG does not support transparency, so you get a solid background, and it is lossy: each time it is saved, some quality is thrown away to keep the file small. That can leave fuzzy edges around text and lines.

PDF

Handy for print and for sharing. A PDF can hold vector artwork, which makes it a common format for sending logos to printers.

AI and EPS

These are the "source" and "exchange" files for professionals. AI is the native file for Adobe Illustrator. EPS is an older vector format that many programs can open. Printers and other designers may ask for them. You do not need them for everyday use, but keep them safe, since they are the master copies.

Which one should you use?

  • Website: SVG, with PNG as a backup
  • Social media profile picture: PNG
  • Email signature or documents: PNG
  • Printing (flyers, signs, t-shirts, banners): PDF, AI or EPS, so the printer gets a vector
  • Giving your logo to another designer: the AI or vector file

A rule worth remembering

Whenever you can, avoid sending a JPG or PNG of your logo to a printer. If it is too small, it may need to be redrawn from scratch.

What to ask your designer for

Ask for a logo pack that includes, at minimum:

  • Vector files (SVG, plus PDF and AI or EPS)
  • PNG files with transparent backgrounds, in a few sizes
  • A version for light backgrounds and a version for dark backgrounds
  • A simple, black-only or one-colour version

If your files do not include a vector version, ask. It is your most useful file.
